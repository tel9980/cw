🌐 API 接口列表

1. 搜索接口

GET
/api/search
搜索客户和订单信息
参数:
  • q - 搜索关键词 (必需)
返回示例: 
{
  "customers": [
    {
      "name": "客户名称",
      "contact": "联系人"
    }
  ],
  "orders": [
    {
      "order_no": "订单号",
      "customer": "客户",
      "amount": 1000.00
    }
  ]
}

2. 统计接口

GET
/api/stats
获取今日统计和待处理订单数
返回示例: 
{
  "today_income": 5000.00,
  "today_expense": 2000.00,
  "pending_orders": 5,
  "unpaid_orders": 3
}

🗂️ 页面路由

路径 方法 说明
/ GET 首页 - 仪表盘
/orders GET 订单列表
/order/new GET, POST 新建订单
/income/new GET, POST 录入收入
/expense/new GET, POST 录入支出
/customers GET 客户列表
/reports GET 报表中心
/api-docs GET API文档页面（当前页面）

📋 使用说明

1. 基础使用

所有API接口均使用标准的HTTP方法，返回JSON格式数据。

2. 错误处理

发生错误时，返回格式如下：

{
  "error": "错误描述信息"
}

3. 状态码

  • 200 - 请求成功
  • 404 - 资源不存在
  • 500 - 服务器内部错误
