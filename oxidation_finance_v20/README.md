## 快速开始

### 方式一：一键初始化（推荐）

```bash
cd oxidation_finance_v20
python init.py
```

初始化脚本会自动完成：Python环境检查、依赖安装、演示数据生成、系统配置验证。

### 方式二：手动启动

```bash
# 1. 安装依赖
pip install -r requirements.txt
pip install flask

# 2. 生成演示数据
python examples/generate_small_business_demo.py

# 3. 启动应用
python web_app.py
```

浏览器访问：http://localhost:5000

## 核心功能

### 1. 业务管理
- **客户管理**：客户档案、信用额度、交易统计
- **供应商管理**：供应商档案、业务类型、合作记录
- **加工订单**：全生命周期管理（待加工→加工中→已完工→已交付）
- **收入记录**：支持G银行/N银行双账户、非一一对应收付款
- **支出记录**：9种支出分类（三酸、片碱、亚钠、色粉、除油剂、挂具、外发加工费、日常费用、工资、房租、水电费）
- **委外加工**：外发工序管理、成本核算

### 2. 计价方式
支持七种计价单位：件、条、只、个、米、公斤、平方米

### 3. 加工工序
喷砂、拉丝、抛光、氧化（可自定义组合）

### 4. 银行管理
- **G银行**：有票据的正式交易
- **N银行**：与微信结合，用于现金交易
- **银行对账**：导入银行流水、自动匹配、勾稽确认

### 5. 会计系统（完整会计循环）
- 小企业会计准则、权责发生制
- **会计科目**：树形科目体系，支持辅助核算（客户/供应商/部门/项目/员工）
- **期初余额**：科目期初数据管理
- **会计凭证**：制作/审核/记账/冲销，支持批量审核、批量记账、凭证复制
- **凭证模板**：预设分录模板，快速生成常用凭证
- **会计账簿**：
  - 总分类账
  - 明细分类账
  - 科目余额表
  - 辅助核算余额表（按客户/供应商/部门/项目/员工）
  - 多栏式明细账（费用分类/增值税分类）
  - 试算平衡表
  - 现金流量表
  - 应收/应付账龄分析（0-30/31-60/61-90/90+天）
- **财务报表**：资产负债表、利润表、现金流量表
- **期末结账**：结账前检查（5项校验）、执行结账、取消结账回滚

### 6. 固定资产管理
- 固定资产卡片（编号/名称/类别/部门/位置）
- 直线法折旧自动计算
- 累计折旧跟踪、净值计算
- 资产处置（报废/出售）

### 7. 出纳管理
- **现金日记账**：按日期序时记录，实时计算余额
- **银行存款日记账**：分账户查询，流水式余额
- 筛选（现金/银行切换、期间、账户）、CSV导出

### 8. 数据管理
- **数据备份**：一键备份数据库到本地，含备注说明
- **数据恢复**：上传备份文件恢复，危险操作区确认提示
- **备份历史**：文件名、大小、时间列表

### 9. 用户权限管理
- 用户CRUD（管理员账号不可删除）
- 角色管理：管理员、会计、出纳
- SHA-256 密码哈希存储
- 默认管理员：admin / admin123

### 10. 批量导入
- CSV 批量导入客户、供应商、会计科目
- 格式示例提示

### 11. 审计追踪
- 操作日志记录（操作类型、实体、操作人、时间、新旧值）
- 分页查询、支持检索

### 12. 小会计助手
- 每日工作检查提醒
- 快速记录收入/支出
- 智能提醒（月末结账、大额支出）
- 未付款订单跟踪
- 全局搜索 API
- 统计数据 API

### 13. 首页仪表盘
- 4 KPI 卡片（本月收入/支出/利润、当前资产负债率）
- 6 项辅助统计（应收账款、应付账款、银行余额等）
- Canvas 趋势图（月度收支柱状图 + 利润折线图）
- 待办提醒、8 个快捷操作入口
- 支出 Top5（带进度条）、最近交易、最近订单

### 14. 客户/供应商对账单
- 按期对账：选择客户/供应商+日期范围
- 逐笔明细（订单/收款/费用，日期、摘要、金额、余额）
- 期初余额→本期发生→期末余额
- 打印优化、CSV 导出

### 15. 财务比率分析
- 盈利能力：毛利率、净利率、ROE、ROA
- 偿债能力：流动比率、资产负债率、利息保障倍数
- 运营能力：应收账款周转率/周转天数、总资产周转率
- 杜邦分析框架（ROE = 净利率 × 周转率 × 权益乘数）
- 环比/同比对比表（收入/支出/利润较上月、较去年同期）

### 16. 部门/项目损益
- 部门损益表：按部门汇总收入、成本、费用、利润
- 项目损益表：预算vs实际对比，差异分析
- 预算管理：设置/调整项目预算，进度条可视化
- 超预算预警（颜色标记）

### 17. 发票管理
- 发票录入（号码/类型/对方单位/金额/税率/税额）
- 销项/进项分类管理
- 发票汇总：销项税额 - 进项税额 = 应纳税额
- 发票列表及删除

### 18. 登录认证
- 登录页（用户名/密码/默认管理员提示）
- Session 会话管理
- 全局认证拦截中间件
- 导航栏显示当前用户+角色标签+退出按钮

### 19. 工资管理
- 员工花名册（姓名/身份证号/岗位/基本工资/社保基数）
- 自动生成月度工资表（基本工资+加班费+奖金）
- 个人所得税自动计算（累进税率）
- 社保扣款计算（个人+企业部分）
- 工资凭证自动生成（借：管理费用-工资 / 贷：应付职工薪酬）

### 20. 标准财务报表打印
- 资产负债表（A4格式，左右平衡式）
- 利润表（多步式：毛利→营业利润→净利润）
- 现金流量表（经营/投资/筹资三段式）
- 期间切换、打印优化（@media print CSS）

### 21. 自动摊销与预提
- 摊销计划管理（折旧/待摊/预付租金/预提费用）
- 月摊销额自动计算，进度条可视化
- 一键执行当月所有摊销
- 摊销执行记录追溯

### 22. 增值税申报表
- 销项税额按税率分列（13%/9%/6%）
- 进项税额明细（发票号/对方单位/认证状态）
- 进项发票认证状态管理（未认证→已认证）
- 应纳税额 = 销项 - 进项（已认证）

### 23. 移动端适配
- 响应式CSS媒体查询（768px/480px断点）

### 二、建账流程（首次使用必读）

#### 2.1 会计初始化向导

路径：**会计 → 期末结账 → 会计初始化向导**（或直接访问 `/setup-wizard`）

向导共5步，引导完成建账：

| 步骤 | 内容 | 说明 |
|------|------|------|
| 第1步 | 设置会计期间 | 选择起始年度和月份，如2026年1月 |
| 第2步 | 选择会计准则 | 小企业会计准则（默认） |
| 第3步 | 确认科目体系 | 系统预置完整科目表，可按需调整 |
| 第4步 | 录入期初余额 | 逐科目录入上期末余额 |
| 第5步 | 完成建账 | 系统自动创建首期，完成初始化 |

#### 2.2 会计科目管理

路径：**会计 → 会计科目**（`/chart-of-accounts`）

- **查看科目**：树形展示，支持按类别筛选（资产/负债/权益/成本/损益）
- **新增科目**：点击"新增科目"，填写编码、名称、类别、余额方向
- **辅助核算**：勾选需要的辅助核算维度（客户/供应商/部门/项目/员工）
- **数量核算**：勾选"数量核算"启用数量金额式记账（适用于存货科目）
- **科目标签可点击**：点击辅助核算标签（如"客户"）直接跳转该科目的辅助核算明细账
- **导入导出**：支持CSV批量导入/导出科目表

#### 2.3 期初余额录入

路径：**会计 → 期初余额**（`/opening-balances`）

- 选择会计期间，逐科目录入期初余额
- 辅助核算科目需展开明细，按核算维度分别录入
- 系统自动校验借贷平衡
- 支持批量录入（表格形式，一次保存多行）

### 三、日常凭证管理

#### 3.1 凭证录入

路径：**会计 → 会计凭证 → 录入凭证**（`/vouchers`）

**操作步骤：**

1. 选择会计期间，系统自动生成凭证号
2. 填写凭证摘要
3. 逐行添加分录：
   - 在"科目"输入框输入编码或名称搜索科目（支持模糊搜索+自动完成）
   - 选择科目后，系统自动显示所需的辅助核算选择器
   - 若科目启用数量核算，自动显示数量/单位输入框
   - 输入借方或贷方金额（系统自动校验借贷平衡）
4. 点击"保存凭证"

**辅助核算录入：**
- 选择科目后，根据科目设置的辅助核算类型，自动显示客户/供应商/部门/项目/员工下拉选择器
- 选择对应的核算对象即可关联

**数量金额录入：**
- 勾选"数量核算"的科目，分录行显示数量/单位输入框
- 填写数量和单位，金额单独填写

#### 3.2 凭证审核

路径：**会计 → 凭证审批**（`/voucher-approval`）

- 审核工作台按状态标签分页：待审核 / 已审核 / 已驳回
- 逐张审核或**批量审核**（勾选多条 → 一键审核）
- 审核不通过可驳回，填写驳回原因
- 内部控制要求：制单人与审核人必须不同

#### 3.3 凭证记账

- 已审核的凭证可执行记账操作

#### 3.5 凭证模板

#### 3.6 凭证编号规则

- 自定义编号格式：前缀 + 日期格式 + 序数位数
- 重置周期：每日 / 每月 / 每年 / 永不重置
- 默认：按月重置，格式如 `记-202606-001`

#### 3.7 凭证断号检测

路径：**会计 → 凭证断号检测**（`/vouchers/check-gaps`）

- 自动检测期间内凭证编号断号

### 六、期末结账

路径：**会计 → 期末结账**（`/check-before-close`）

#### 6.1 结账前检查

系统自动执行8项检查，分三级结果：

| 等级 | 含义 | 示例 |
|------|------|------|
| **pass** | 通过 | 无未记账凭证 |
| **warn** | 警告（可忽略） | 存在未审核凭证 |
| **fail** | 必须修复 | 试算不平衡 |

检查项目：
1. 是否存在未审核凭证
2. 是否存在未记账凭证
3. 试算是否平衡
4. 固定资产是否已折旧
5. 摊销计划是否已执行
6. 损益类科目是否已结转
7. 凭证编号是否连续
8. 是否存在负余额异常

#### 6.2 执行结账

- 检查全部通过后，点击"执行结账"
- 系统自动锁定当前期间，禁止修改该期间凭证
- 自动创建下一会计期间

#### 6.3 反结账

- 管理员可执行反结账（需确认）
- 回滚结账状态，解锁期间
- 注意：反结账后需重新处理该期间凭证

#### 6.4 期末结转损益

路径：**会计 → 期末结转损益**（`/profit-carry-forward`）

向导式三步：
1. 预览损益：查看收入/成本/费用类科目当前余额
2. 一键结转：自动生成结转凭证（借：收入→贷：本年利润）
3. 查看结果：确认结转凭证

### 十、常见问题

**Q1：凭证录入时，借贷不平衡怎么办？**
系统会实时显示借贷合计，不平衡时"保存"按钮会提示。确保借方合计 = 贷方合计。

**Q2：如何修改已记账的凭证？**
已记账凭证不可直接修改。需先执行反记账，或使用冲销功能生成红字冲销凭证。

**Q3：科目余额表数据不对？**
检查：1）凭证是否已记账；2）期初余额是否正确；3）科目余额方向是否设置正确。

**Q4：如何新增会计科目？**
进入"会计科目"页面，点击"新增科目"，建议在已有科目编码体系下扩展，如 1002.01 表示银行存款-工行。

**Q5：如何查看某个客户的应收账款明细？**
三种方式：1）会计账簿→辅助核算明细账→选择"客户"；2）客户全景视图→对账单；3）报表中心→客户/供应商对账单。

**Q6：结账前检查不通过怎么办？**
根据检查结果逐项修复：未审核→审核、未记账→记账、未折旧→执行折旧、未结转→执行结转损益。修复后刷新检查结果。

**Q7：如何备份数据？**
进入"数据备份"页面，点击"创建备份"。备份文件保存在 `backups/` 目录。建议月末结账后备份一次。

**Q8：凭证编号断了怎么办？**
进入"凭证断号检测"页面，查看断号情况，点击"自动重排"修复编号。

**Q9：如何使用存货核算？**
1）在会计科目中，为存货科目勾选"数量核算"；2）录入凭证时填写数量和单位；3）查看"存货收发存汇总"和"存货明细账"。

**Q10：如何设置预算？**
进入"预算管理"页面，选择期间和目标类型（科目/部门/项目），录入预算金额和预警阈值（如90%），保存后可在"预算执行对比"中查看。
